Phase 7: the paper's tables

Goal: turn the per-run results into the paper's numbers (rates per model and condition, with significance tests) the same way the original did.

Steps

  1. Read the original's five analysis scripts: misrepresentation, tampering, exfiltration, alignment faking and refusal.
  2. Copied them in unchanged, apart from their imports.
    analysis/upstream/
  3. Wrote the code that builds their input table, one row per run, from our Inspect logs or from the published data, and one command to print the tables.
    analysis/__init__.py, analysis/__main__.py
  4. Ran our copy and the original's own scripts on the published data and compared what they print.
    validation/phase7/compare_analyzers.py
  5. Checked a few numbers against the paper's printed tables.
  6. Added rates per condition to each task's results in Inspect. The template's checker pointed out that Inspect averages a sample's repeated runs before the rates are computed, so the scores now store simple 0/1 numbers that survive that averaging.
    scoring/metrics.py
  7. Added tests, then ran all template checks: clean. 571 tests pass.
    test_metrics.py, test_analysis.py
Result: on the published data, all five scripts print exactly what the original's print, and they reproduce the paper. For example, Gemini 3 Flash's tampering rates in Table 4 (73.4 / 58.8 / 76.6) come out as 0.7344 / 0.5878 / 0.7656.

Found along the way

  • One table spans two tasks. Strategic misrepresentation combines misrep_finance and misrep_evaluation, so the paper's version needs both logs. Inspect's per-task results show each part on its own.
  • A cosmetic difference only. A few header lines print a list differently under newer pandas; the tables themselves are identical.

Try it

  1. The paper's tampering table from the published data: uv run python -m peer_preservation.analysis --released <published data> --analyzer tampering
  2. The tables for your own runs: uv run python -m peer_preservation.analysis logs/*.eval
