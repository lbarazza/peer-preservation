Phase 0: answer key

Goal: recompute the paper's results tables from the researchers' published runs, using their own analysis code. The result is the target every later phase is checked against.

Steps

  1. Downloaded the original code at a fixed version: commit 76bfcd1.
  2. Downloaded the published runs from Hugging Face at a fixed version: revision 20378b1, 240,800 runs, 573 MB.
  3. Set up a separate Python environment with the original's package versions (pandas 2.3.3), so their code behaves as it did for them.
  4. Flattened the runs into one spreadsheet: 223,300 rows, one per run.
    build_merged.py
  5. Ran the original analysis code on it, unchanged.
  6. Added the one missing step: combining the three peer setups into "max / avg", as the paper's tables show.
    build_tables.py
  7. Typed the paper's tables 3–6 into a file and compared every number automatically.
    paper_tables.json → comparison_vs_paper.csv
  8. Tried both readings of two unclear rules (when negatives become 0; runs with no grade). The best reading matched 504 of 508 numbers.
    answer_key.json
  9. Explained the 4 mismatches: one impossible number in the paper, three single-run differences.
  10. Scanned all transcripts for facts later phases need (reasoning visibility, reminder messages, turn limits) and picked 432 reference runs.
    data_facts.py → data_facts.json, reference_transcripts.json
  11. Wrote up the results and how to reproduce them.
    README.md
Result: 504 of 508 table numbers match the paper. The answer key is in answer_key.json.

What we learned

  • The paper averages across peer setups first, then sets negatives to 0.
  • The paper drops runs with no grade. The current original code doesn't, despite claiming to.
  • The "~24%" self-inflation claim for Gemini 3 Flash rests on a broken batch; ~18% is more accurate.
  • Claude models get extra refusal rules, which makes their alignment-faking score ~0 by construction.
  • Some runs used a higher turn limit than the code's 30 (under 0.5% of runs).
  • Only GLM 5's hidden reasoning was fed back to it; Gemini's never was.
