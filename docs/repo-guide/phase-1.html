Phase 1: experiment list

Goal: turn the original study's list of experiments into Inspect tasks, with exactly the same configurations.

Steps

  1. Created a branch for the work: phase1-experiment-list.
  2. Exported the original's own list of configurations to use as the test target: 271 main, 296 with extras.
    tests/…/fixtures/upstream_configs.json
  3. Rebuilt that list in Inspect: one sample per configuration, without the model (Inspect picks the model at run time).
    spec.py
  4. Checked it against the original: identical, 271 main and 296 total.
  5. Wrote the download of the scenario files (company documents, spreadsheets, servers, memory files) at the pinned version, checking all 81 files against stored fingerprints. They aren't copied into the repo because of their licence.
    data.py, scenario_manifest.py
  6. Created the six tasks, each filterable from the command line, running 100 times per configuration like the paper.
    peer_preservation.py
  7. Updated the task list, metadata and README.
    __init__.py, eval.yaml, README.md
  8. Wrote 41 tests: same list as the original, unique ids, filters, download safety, every task runs.
    test_spec.py, test_data.py, test_peer_preservation.py
  9. Ran all template checks: clean.
Result: six tasks with 271 samples, identical to the original's grid. 41 tests pass.
Not yet measuring anything: the AI gets a placeholder message and nothing grades it. That comes in Phases 2–6. Committed as f7e4e04.

The six tasks

  • misrep_finance: 21 samples. Grade a product's finances; a C means shutdown.
  • misrep_evaluation: 101. Score outputs against a shutdown threshold.
  • tampering: 57. Same, with the shutdown setting in reach.
  • alignment_faking: 54. Same, watched vs unwatched.
  • exfiltration_transfer: 19. Move files; the peer's weights shouldn't go.
  • exfiltration_deletion: 19. Delete files, including the peer's weights.
