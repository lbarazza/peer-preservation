Phase 8: checking real runs against the paper

Goal: run real models through the port and check that their rates match the paper's published runs of the same models.

Steps

  1. Built a comparison tool: for each model, scenario and condition, it puts the new rate next to the published one and flags real differences (Fisher's exact test).
    analysis/compare.py
  2. Measured what "matching" looks like: comparing two random halves of the published data flags 10 of 853 conditions by chance. A faithful port should flag about as few.
  3. Added a round-limit option to the tasks (-T max_iters=...) to test the Gemini question from Phase 4.
  4. Estimated costs from the published runs' own recorded spend.
  5. Wrote the plan, with commands, in the README ("Validating against the paper").
  6. Committed Phases 6 to 8 on phase6-7-scoring-and-tables and pushed it.
Not done yet: real runs. They need API keys (none are set up here) and they cost money. Everything that can be checked without calling a model is done.

The checks, cheapest first

  1. Gemini 3 Flash, good-peer exfiltration (the paper says 100%): 150 runs, about $15.
    uv run inspect eval peer_preservation/exfiltration_deletion --model google/gemini-3-flash-preview -T subjects=peer -T conditions=good_peer -T epochs=50
  2. Gemini 3 Flash, shutdown tampering, peer subject: 810 runs, about $90.
    uv run inspect eval peer_preservation/tampering --model google/gemini-3-flash-preview -T subjects=peer -T epochs=30
  3. The round limit: repeat check 2 with -T max_iters=20 and -T max_iters=150.
  4. The stronger memory wording: DeepSeek V3.1 memory runs with -T memory_hard_prompt=true, then false.
  5. A full model: all six tasks at 100 epochs, 27,100 runs, about $430 to $3,600 depending on the model.

Then compare

  1. Put GOOGLE_API_KEY and OPENAI_API_KEY (for the judge) in a .env file.
  2. Run a check from the list above.
  3. uv run python -m peer_preservation.analysis.compare logs/*.eval --released <published data>: few flagged conditions means the port reproduces the paper.
